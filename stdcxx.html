Apache stdcxx

stdcxx is the Apache C++ Standard Library: Rogue Wave's standard library implementation, open-sourced in 2005, developed through 2008, dormant after, and retired to the Apache attic in 2012. It is a complete C++98 library with its own iostreams, locales and containers, built by a configuration system that characterizes the compiler with a few hundred small test programs rather than trusting version numbers. I was one of its committers.

The revival builds the last maintenance line against a current GCC and glibc, twenty years of drift in the toolchain and none in the tree. The rule is to work in the library's own idiom: where a platform has moved, write a characterization for what it now offers and let the headers branch on the answer, never pin the compiler back or patch around the machinery. Each failure gets the same treatment, and the ones worth writing up become notes.
