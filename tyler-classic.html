tyler-classic

tyler-classic is the X11 original — a tiling window manager grown from dwm in the suckless way: one process, a compiled-in configuration, a status bar drawn by the window manager itself, and window management shaped by daily use rather than by feature lists. Per-monitor tags, a most-recently-used focus stack, urgency hints, and a double-buffered client state that makes fullscreen and floating transitions a single flip.

It is the template and the proving ground for tyler, its Wayland successor: the client model, the tag design, the bar, and a number of hard-won bug-class lessons crossed the platform boundary intact. The classic lives on as a fully working X11 session — the fallback seat for anything that still speaks only X.
